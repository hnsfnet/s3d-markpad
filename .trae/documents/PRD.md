## 1. 产品概述

纯浏览器端 Markdown 笔记应用，无需后端服务，所有数据存储在本地 localStorage。为用户提供简洁高效的笔记编写体验，支持 Markdown 实时预览与自动保存。

- 核心价值：零配置、即开即用的 Markdown 笔记工具，数据完全本地化，隐私安全
- 目标用户：需要快速记录笔记、编写 Markdown 文档的个人用户
- 市场定位：轻量级、离线可用的本地笔记解决方案

## 2. 核心功能

### 2.1 功能模块

1. **笔记列表模块**：左侧侧边栏，展示所有笔记列表，支持新建、删除笔记
2. **Markdown 编辑器模块**：右侧上半区域，支持 Markdown 语法编写
3. **实时预览模块**：右侧下半区域，实时渲染 Markdown 内容
4. **自动存储模块**：后台自动保存到 localStorage，无需手动操作

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主页面 | 笔记列表 | 展示笔记标题列表，高亮当前选中笔记，支持新建/删除操作 |
| 主页面 | Markdown 编辑器 | 文本编辑区域，支持标题、加粗、斜体、列表、链接、图片、代码块等基本 Markdown 语法 |
| 主页面 | 实时预览 | 同步渲染编辑器内容，正确解析 Markdown 语法为 HTML |
| 主页面 | 自动保存 | 监听内容变化，防抖保存到 localStorage；切换笔记、关闭页面时确保数据不丢失 |

## 3. 核心流程

用户打开应用 → 加载 localStorage 中存储的笔记列表 → 点击笔记或新建笔记 → 在编辑器中编写 Markdown 内容 → 下方实时预览渲染效果 → 内容自动保存到本地存储 → 切换/关闭页面时数据持久化。

## 4. 用户界面设计

### 4.1 设计风格

采用「简约编辑室」风格，偏向 Typora/Notion 类编辑器的宁静质感：

- **主色调**：柔和米白背景 (`#fafaf8`)，深灰文字 (`#2c2c2c`)，暖橙色强调 (`#e07a3c`)
- **次级色**：侧边栏浅灰 (`#f0efe9`)，边框浅灰 (`#e5e4dd`)，代码块深灰 (`#282c34`)
- **按钮风格**：圆角 8px，悬浮时微阴影 + 背景色变化，点击时有轻微缩放反馈
- **字体**：标题使用 `Playfair Display` 衬线字体增添书卷气，正文使用 `Inter` 保证可读性，代码使用 `JetBrains Mono` 等宽字体
- **布局风格**：三栏式结构（左侧列表 + 右上编辑器 + 右下预览），清晰的垂直/水平分割线，适度留白

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI Elements |
|-----------|-------------|-------------|
| 主页面 | 笔记列表 | 固定宽度 280px，浅灰背景，笔记项 hover 高亮，选中项暖橙色左侧边框，顶部新建按钮，悬停显示删除图标 |
| 主页面 | 编辑器 | 白色背景，JetBrains Mono 字体，行高 1.6，内边距 24px，无边框，焦点时无轮廓 |
| 主页面 | 预览区 | 白色背景，Inter 字体，标题 Playfair Display，代码块深色背景语法高亮，适当的段落间距 |
| 主页面 | 分割线 | 可拖拽的水平/垂直分割器，悬浮时显示橙色高亮 |

### 4.3 响应式

桌面端优先设计，针对笔记本屏幕优化。移动端（< 768px）采用上下布局：
- 笔记列表可折叠收起
- 编辑器与预览区垂直堆叠，可通过标签切换

### 4.4 动效与交互

- 笔记项 hover：背景色柔和过渡（150ms ease）
- 新建笔记：列表项淡入动画（200ms ease-out）
- 删除笔记：列表项淡出 + 高度收缩（250ms ease）
- 输入内容：预览区同步更新，轻微的内容淡入过渡
- 分割线拖拽：实时更新布局，无延迟
